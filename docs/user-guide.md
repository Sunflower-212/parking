# 操作手册

## 首次准备

1. 按 README 启动系统，打开 http://localhost:8088。
2. 在登录页选择管理员身份，使用本地 `.env` 中的首次管理员账号和密码登录。
3. 创建计费规则和停车场，再进入车位管理绘制地图。没有真实空闲车位的停车场不能预约或接收入场。
4. 注册普通用户并完善个人资料及车牌，再测试预约。

首次账号只在数据库中没有超级管理员时创建。修改环境变量不会覆盖已存在账号的密码。

## 普通用户

### 注册与登录

在登录页切换到注册表单，填写 3 至 16 位用户名和密码；确认密码保持一致。注册成功后返回登录页，选择用户身份登录。

进入个人中心填写姓名、车辆颜色、手机号和车牌。车牌沿用项目格式，例如 `京A-12345`，字母应大写。后端以当前登录身份更新资料，不能通过修改请求中的用户 ID 操作他人资料。

### 预约车位

1. 打开“车位预约”，选择停车场及楼层。
2. 点击空闲车位，再点击“预约”。一次只能预约一个车位。
3. 成功后页面显示预约记录。默认应在 30 分钟内入场；时限由部署配置决定。
4. 取消预约时点击记录中的“取消预约”并确认。

已预约或已在场的用户不能重复预约。并发被他人占用时，界面会提示刷新重试。车位过期后由延迟队列自动释放，页面重新查询或刷新即可看到最新状态。

已入场后不能取消预约；此时应由管理端处理车辆离场。到期的旧消息不会影响后续的新预约。

### 账户与历史

- 入场历史：按停车场、日期查看预约及出入场记录。
- 订单历史：查看停车时长、计费金额及离场记录。
- 充值历史：查看待支付、已支付和取消状态。
- 账户：查看余额及会员信息。现有会员开通和续期逻辑保持不变，未另行新增会员收费规则。
- 密码：修改密码后需要重新登录；登出清除当前会话。

充值依赖已启用的支付宝服务。微信支付尚未接入。支付页面返回不等于到账，到账以通过验签的服务端支付回调为准，重复回调不会重复增加余额。

头像上传依赖 OSS；未配置时会提示云存储尚未启用。

## 停车场管理员

### 停车场和地图

创建或维护自己管理的停车场，并选择计费规则。停车容量由地图中的实际车位决定，不能通过修改总数来绕过预约占用状态。

车位类型包括空闲、占用、道路、墙壁和出入口。地图新建、编辑支持空闲及地图元素；占用状态必须通过预约或出入场流程产生。预约中或在场车位不能直接修改或删除。

批量操作包含其他管理员的车位时，整个操作拒绝，不执行部分越权删除。

### 出入场

在出入场管理页面选择本停车场，上传受支持的车牌图片。此功能需要先配置百度识别服务。

- 已有本停车场有效预约：转为入场，保留原车位，不重复减少余位。
- 无预约：分配 ID 最小的空闲车位；没有空位则拒绝。
- 预约属于其他停车场：需要先取消原预约。
- 出场：校验车辆在此停车场、计算费用并扣款，再释放车位。
- 余额不足：出场事务失败，车辆及车位保持原状态。

图片上传仅接受不超过 5MB 的 JPEG 或 PNG。车牌识别失败不会创建出入场记录。

### 用户和统计

普通管理员查看所属停车场的停车订单与运营统计。平台用户资料、密码重置、用户导出、充值流水和平台用户指标仅超级管理员可访问。共享计费规则的修改、删除由超级管理员执行。

超级管理员的密码重置按钮保留项目原有“重置为 123456”的行为，并使旧 Token 失效。重置后通知账号持有人自行修改密码。

## 超级管理员

除停车场管理能力外，可管理平台用户、充值流水、全部停车场和管理员账号，并维护共享计费规则。

通过管理员管理页面新增账号并分配权限：`0` 为停车场管理员，`1` 为超级管理员。管理员注册接口需要超级管理员权限，普通用户不能注册管理员。

新建管理员及管理端添加用户沿用原界面的账号初始密码规则：初始密码与账号名相同。首次进入后使用个人密码修改功能更新。管理员删除自己会被拒绝，有关联数据的账号或停车场不能直接删除。

## 新界面操作说明

侧边栏支持折叠，手机上点击顶部菜单图标打开导航。搜索后从第一页开始；列表支持每页 10/20/50/100 条，刷新失败会显示重试入口。

地图支持拖动平移、滚轮或按钮缩放。可通过地图或下方分页列表选择车位；普通用户只能预约一个空闲车位。地图在页面可见时每 15 秒刷新，隐藏后暂停；预约结果仍由服务端事务确认。

运营概览可选择停车场与近 7/14/31 天范围。页面显示数据时间，统计最长缓存 30 秒。入场统计排除尚未入场的预约；停车收入按订单创建日统计，平台充值按充值单创建日统计成功记录。

管理端“修改密码”和用户端“修改密码”均校验原密码，成功后要求重新登录。新建用户时填写的姓名、车牌、颜色及手机号会一并保存；存在关联记录的用户不能直接删除。

账户页在返回页面和操作成功后刷新余额与会员资料。第三方未启用时，相关按钮会明确标识不可用；不发起实际识别、支付或云上传请求。

## 常见提示

| 提示 | 处理方式 |
| --- | --- |
| 登录失效 | 重新登录；重新登录会替换先前 Token |
| 无权操作此停车场 | 检查当前管理员及停车场归属 |
| 已有预约或车辆在场 | 先取消预约或完成离场 |
| 无可用车位 | 检查车位地图及现有预约/在场记录 |
| 旧记录缺少车位关联 | 联系运维核对迁移报告，不能直接释放车位 |
| 第三方服务尚未启用 | 按部署手册配置服务开关及密钥 |
| 网络异常 | 检查服务状态和代理配置；失败请求不会显示为成功 |
